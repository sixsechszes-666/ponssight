the vault

locked
there is no reset and no recovery: the passphrase is not stored on this machine or anywhere else, so a typo here locks away every key added under it. write it down first, and use a few words rather than one - a short passphrase is the cheapest way into the file.
keys are encrypted with this passphrase before they are stored, so data/pons.db, its log, and every copy of this folder are useless without it. the passphrase is held in the server's memory and nowhere else: it is not written down, no endpoint returns it, and it is gone on restart or when you press lock. while the vault is open, anything running as you on this machine can read the keys it holds.
